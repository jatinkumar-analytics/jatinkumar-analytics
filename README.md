## Analytics delivery workflow

```text
LAND → PROFILE → TRANSFORM → MODEL → TEST → SERVE
```

| Stage | What I focus on |
|---|---|
| **Land** | Source traceability, cloud storage, stages, Lakehouse and Warehouse ingestion |
| **Profile** | Schemas, datatypes, nulls, duplicates, keys and row-count reconciliation |
| **Transform** | Modular SQL, dbt models, Jinja logic and basic PySpark transformations |
| **Model** | Declared grain, Fact and Dimension design, star schemas and semantic models |
| **Test** | Uniqueness, not-null, relationships, business rules and source-to-target validation |
| **Serve** | Analytics-ready models, DAX KPIs and stakeholder-focused Power BI reporting |

## Featured engineering projects

### Airbnb Analytics Engineering Pipeline

**AWS S3 · Snowflake · dbt Core · SQL · Jinja · SCD Type 2**

Built an end-to-end analytical pipeline that transforms Airbnb source files into tested, analytics-ready Fact and Dimension models.

- **5,700 source records:** 5,000 bookings, 500 listings and 200 hosts
- Layered **Bronze, Silver and Gold** dbt transformations
- Booking-grain `FACT_BOOKINGS` with Listing, Host and Date Dimensions
- **2 SCD Type 2 snapshots** for historical Listing and Host attributes
- **32 dbt tests** covering keys, nulls, relationships and business calculations
